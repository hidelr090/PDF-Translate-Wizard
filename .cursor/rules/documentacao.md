# Rule: Regras de Documentação

1. **Contrato de API alterado** → atualizar Swagger/OpenAPI no `homefinapp-api`.
2. **Nova variável de ambiente** → atualizar `.env.example` e docs de setup do app.
3. **Mudança de comportamento para o usuário** → atualizar docs na pasta `docs/` do app correspondente.
4. **Decisão arquitetural relevante** → registrar brevemente no PR ou em `docs/`.

## Quando aplicar
Sempre que houver mudança de contrato, variável de ambiente, comportamento do usuário ou arquitetura.
