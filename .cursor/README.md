# 🧠 Personas, Skills e Rules — Workspace PDF Translate Wizard

Este diretório concentra as **personas, skills e rules** próprias para o desenvolvimento diário do projeto **PDF Translate Wizard**.

## Estrutura

```
.cursor/
├── personas/   # Perfis de atuação (quem desenvolve e com que foco)
├── skills/     # Competências técnicas (o que se sabe fazer e como)
└── rules/      # Regras de convênio de código (como se deve fazer)
```

## Como usar

- **Personas**: escolha a persona antes de iniciar uma tarefa grande para alinhar o tom, foco e preocupações (ex: "atue como persona Backend").
- **Skills**: use como checklist de competência ou referência rápida de boas práticas por tecnologia.
- **Rules**: regras obrigatórias e convenções que se aplicam a pull requests, commits e revisão de código.

## Stack do projeto

O projeto PDF Translate Wizard é um aplicativo para tradução de arquivos PDF. Adapte as personas, skills e rules abaixo à sua stack conforme o projeto evoluir.

> Todas as regras e skills estão escritas em português e alinhadas com as convenções já existentes no projeto.
